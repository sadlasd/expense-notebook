# Кошелёк

Учебный проект на React для учёта повседневных расходов. Покупки можно добавлять по категориям, просматривать за месяц и удалять с возможностью отмены последнего действия.

[Демо](https://wallet-pakhomov.kibervanya.chatgpt.site) · [Репозиторий](https://github.com/sadlasd/expense-notebook)

Демо в Sites пока доступно только владельцу. Исходники репозитория публичные.

## Что умеет

- Добавление покупки с названием, суммой, категорией и датой.
- Выбор месяца и фильтрация истории по категории.
- Итог расходов, количество покупок и самая большая трата.
- Простые полосы распределения по категориям.
- Удаление и отмена последнего изменения.
- Сохранение записей в localStorage.
- Адаптивная версия для телефона.

При первом открытии показаны вымышленные расходы за текущий месяц. Кнопка «Начать пустой список» убирает пример. Первая добавленная покупка тоже заменяет пример твоими записями. Возвратить предыдущий список можно кнопкой отмены.

## Стек

React, JavaScript, CSS, Vite. Отдельных библиотек для состояния, форм и графиков нет.

## Запуск

Понадобится Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Адрес приложения появится в терминале.

```sh
npm run build    # сборка в dist
npm run preview  # просмотр готовой сборки
```

## Структура

```text
src/
  App.jsx            — состояние, фильтры, список и итоги
  ExpenseForm.jsx    — форма добавления покупки
  expenses.js        — категории, проверка данных, форматирование сумм
  useSummaryTool.js  — необязательная интеграция WebMCP для чтения итогов
  main.jsx           — точка входа
  styles.css         — стили и мобильная версия
```

## Основные решения

Записи хранятся в массиве. `filter` отбирает месяц и категорию, `reduce` складывает суммы. Компонент формы передаёт данные главному компоненту через `onAdd`.

Суммы хранятся целыми числами в копейках: 125,50 ₽ — это 12550. Так итог не зависит от неточного сложения дробных чисел в JavaScript. Допускаются точка и запятая, максимум два знака после разделителя. Даты хранятся строками `YYYY-MM-DD` и не переводятся в UTC при отображении.

При изменении списка `useEffect` сохраняет его в localStorage. Перед загрузкой проверяется формат сохранённых данных. Если браузер запрещает запись, приложение показывает сообщение.

В браузере с WebMCP доступно чтение итогов из чата. В других браузерах интеграция не включается и не влияет на работу приложения.

## Ограничения

Записи доступны только в одном браузере и не синхронизируются между устройствами. Это не банковское приложение: подключений к счетам нет. Поддерживается только рубль. Можно отменить одно последнее изменение до перезагрузки страницы. Редактирования расходов пока нет.

## Проверка вручную

1. Добавить 100,10 ₽ и 200,20 ₽: итог должен быть 300,30 ₽.
2. Выбрать другую категорию: меняется история, а итог месяца остаётся общим.
3. Добавить покупку за другой месяц: выбранный месяц переключается на её дату.
4. Удалить запись и отменить удаление: покупка возвращается.
5. Перезагрузить страницу: список сохраняется.
